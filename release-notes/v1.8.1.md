## New
- A one-time invitation to review LexiBridge, shown in the popup only, after 7 days since install (or since the first update for existing users) and 50 words marked known. Any choice, or closing it, ends it for good.
- Microsoft Edge support: the review link opens the right store (Chrome Web Store or Edge Add-ons) based on the extension ID.
- Search-friendly store names and summaries for Simplified Chinese, Traditional Chinese and Japanese.

## Website
- A language menu, and the visitor's language on first visit.
- The privacy policy now names Microsoft Edge alongside Chrome.

## Install
The [Chrome Web Store](https://chromewebstore.google.com/detail/mnhdbmjfgoohoajakjkeminblgnbmlhp) is recommended, since it updates automatically.

Manual install: download `lexibridge-1.8.1.zip` below and unzip it, turn on Developer mode in `chrome://extensions`, click **Load unpacked** and pick the unzipped folder. See the install guide: [简体中文](https://chanmo.github.io/LexiBridge/install.html) · [繁體中文](https://chanmo.github.io/LexiBridge/zh-TW/install.html) · [日本語](https://chanmo.github.io/LexiBridge/ja/install.html).
