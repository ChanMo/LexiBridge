* LexiBridge

LexiBridge 是一个免费开源的 Chrome 扩展：读英文网页时，只标出你还不认识的词，
点一下看释义，认识了就移出。不翻译整页，数据只保存在本地浏览器。

官网：https://chanmo.github.io/LexiBridge/


** 名字来源
LexiBridge：这个名称将“lexicon”（词汇）和“bridge”（桥梁）两个词结合起来，
表示插件可以将用户与其他语言的词汇连接起来。


** 开发

没有依赖，也不需要构建：在 =chrome://extensions= 中"加载已解压的扩展程序"，选择仓库根目录即可。

#+begin_src sh
npm test          # 单元测试 (node:test)
npm run package   # 生成 dist/lexibridge-<version>.zip，用于上传应用商店
#+end_src

- =lexicon.js=: 分词、词形还原、释义解析，内容脚本、管理页和测试共用
- =script.js=: 内容脚本，负责高亮和交互
- =ui.js=: 网页内的单词卡片、加词按钮、提示条 (Shadow DOM，不受网页样式影响)
- =background.js=: 安装初始化、TTS 发音、从内置词库查释义
- =popup.*=: 扩展图标弹出面板
- =options.*=, =level.*=, =blacklist.*=: 管理页 (单词库、英语水平、禁用网站)，共用 =pages.css= 和 =page.js=
- =levels.js=: 水平定义，由内置词表做差集生成词库
- =icons/=: 图标 SVG 源文件 (商店 128 / 满版 / 工具栏小尺寸) 和界面图标 =ui.svg=；
  =icons/render.js= 导出 PNG

** 官网

=docs/= 是 Jekyll 源文件，由 GitHub Pages 直接构建 (Settings → Pages → Deploy from a branch → =main= / =docs=)，
不需要本地构建，也不提交构建产物。只用 GitHub Pages 自带的 Jekyll 功能，没有主题和插件。

- =_config.yml=: 商店链接、GitHub 链接等站点变量
- =index.html=: 首页，含可点击的演示 (=assets/demo.js=)
- =install.md=, =privacy.md=: 安装说明、隐私政策
- =assets/site.css=: 全站样式，品牌色与扩展一致，支持深色模式

本地预览 (可选)：=jekyll serve --source docs=，然后打开 http://localhost:4000/LexiBridge/

** 品牌

墨与荧光笔：墨蓝 =#1f2a44= 为主色，荧光金 =#f5b83d= 为标记色，纸色 =#f7f1e3= 为底色。
网页上的下划线高亮用 =#c98400=。高亮色避开蓝/紫 (链接) 和红 (拼写错误)。
