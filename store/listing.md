# Store listing (Chrome Web Store, Edge Add-ons)

The name and summary come from `_locales/*/messages.json` (`extName`, `extDescription`; the summary
must stay within 132 characters). The detailed descriptions below are pasted into each store's
dashboard by hand. Keywords are guesses, not backed by search data.

Rules for every language: levels are a reference ("参考 / 參考"), never "official"; the data sources
are credited at the end; CEFR-J is cited in the form its authors ask for.

## zh-CN

**Detailed description**

```
读英文网页时，LexiBridge 只标出你还不认识的词。点一下看音标、词性和释义，认识了就移出。不翻译整页，不打断阅读。

【怎么用】
1. 选好你的英语水平：入门、大学四级、大学六级、GRE，共四档。你已经掌握的词不会被标出来，比你的水平更难的词都会标出。
2. 照常阅读：生词下面有一道金色笔划，点一下就能看到释义，还能朗读发音。
3. 认识了就移出：词库会随着你变小；遇到新的生词，选中它就能加入。

【特点】
· 只标生词，不翻译整页，原文一字不改
· 认得变形词：studies、making、went 都能找回原形
· 词库只存在你的浏览器里，不需要账号，没有服务器，不上传任何数据
· 可以按网站关闭，可以导入导出词库
· 免费开源（MIT），代码在 GitHub：https://github.com/ChanMo/LexiBridge

【数据来源】
词典与分级：ECDICT（MIT 许可证）。档位划分仅供参考，不是任何考试的官方词表。
```

**Keywords**: 背单词、生词高亮、四六级、考研英语、GRE、英语阅读、英语学习

## zh-TW

**Detailed description**

```
讀英文網頁時，LexiBridge 只標出你還不認識的單字。點一下看音標、詞性和釋義，認識了就移出。不翻譯整頁，不打斷閱讀。

【怎麼用】
1. 選好你的英文程度：國中、高中・學測、全民英檢中高級、GRE，共四個程度，參考 CEFR-J 分級。你已經會的單字不會被標出來，比你的程度更難的單字都會標出。
2. 照常閱讀：生字下面有一道金色筆畫，點一下就能看到釋義，還能朗讀發音。
3. 認識了就移出：單字庫會隨著你變小；遇到新的生字，選取它就能加入。

【特色】
· 只標生字，不翻譯整頁，原文一字不改
· 繁體中文釋義；瀏覽器語言是繁體中文時自動使用，也可以切換成簡體中文
· 認得變化形：studies、making、went 都能找回原形
· 單字庫只存在你的瀏覽器裡，不需要帳號，沒有伺服器，不上傳任何資料
· 可以依網站關閉，可以匯入匯出單字庫
· 免費開源（MIT），程式碼在 GitHub：https://github.com/ChanMo/LexiBridge

【資料來源】
詞典：ECDICT（MIT 授權），以 OpenCC 轉為繁體。分級參考 CEFR-J Wordlist，僅供參考，不是全民英檢、學測或任何考試的官方單字表。
The CEFR-J Wordlist Version 1.6. Compiled by Yukio Tono, Tokyo University of Foreign Studies. Retrieved from https://www.cefr-j.org/download.html on 08/10/2026.
```

**Keywords**: 單字、背單字、英文生字、學測、多益、全民英檢、英文閱讀
