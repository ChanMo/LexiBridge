## 从 Chrome 应用商店安装

1. 打开 [LexiBridge 的商店页面]({{ site.store_url }})。
2. 点击 **添加至 Chrome**，在弹出的确认框中选择 **添加扩展程序**。
3. 安装完成后会自动打开 **英语水平** 页面，选一个适合你的水平即可开始使用。

Microsoft Edge 等基于 Chromium 的浏览器也可以从 Chrome 应用商店安装。

## 手动安装

适用于无法访问 Chrome 应用商店的情况。手动安装的版本不会自动更新。

1. 在 [GitHub 版本列表]({{ site.github_url }}/tags) 中下载最新版本的 **Source code (zip)**，然后解压。
2. 在 Chrome 地址栏输入 `chrome://extensions` 并回车。
3. 打开右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择解压后的文件夹（里面有 `manifest.json` 文件）。

### 更新手动安装的版本

下载并解压新版本，覆盖原来的文件夹，然后在 `chrome://extensions` 中点击 LexiBridge 卡片上的刷新按钮。你的词库和设置会保留。

## 开始使用

- **选择水平**：在 **英语水平** 页面选择入门、大学四级、大学六级或 GRE 核心。你已经掌握的词不会被标出来。
- **查看释义**：打开任意英文网页，生词下面会有一道金色笔划。点击就能看到音标、词性和释义；链接里的生词，把鼠标停在上面即可。
- **移出认识的词**：在单词卡片上点击 **认识了**，这个词就不会再被标出。点错了可以撤销。
- **加入新词**：选中网页上的一个英文单词，点击出现的 **加入词库** 按钮。
- **在某个网站上关闭**：点击浏览器工具栏里的 LexiBridge 图标，关闭当前网站的开关。

## 系统要求

Chrome 114 或更新版本，以及同等版本的 Edge 等 Chromium 浏览器。
