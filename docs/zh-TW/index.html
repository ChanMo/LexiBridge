為什麼做 LexiBridge

讀英文原文時，常見兩種做法：英文好的人遇到生字就跳過去，英文沒那麼好的人乾脆整頁翻譯。前一種讀完了，單字沒學到；後一種看懂了，讀原文的能力卻沒練到。

LexiBridge 想走中間那條路：保留原文，只把你缺的那幾個字補上。每讀一篇文章，就順手認識幾個字；認識了，它就不再出現。

這是一個開源專案，歡迎在 GitHub 上提建議或參與開發。
