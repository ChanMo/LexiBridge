## 從 Chrome 線上應用程式商店安裝

1. 打開 [LexiBridge 的商店頁面]({{ site.store_url }})。
2. 點選 **加到 Chrome**，在跳出的確認視窗中選擇 **新增擴充功能**。
3. 安裝完成後會自動打開 **英文程度** 頁面，選一個適合你的程度即可開始使用。

如果瀏覽器的語言是繁體中文，安裝後會自動使用繁體中文釋義和台灣常用的分級。Microsoft Edge 等以 Chromium 為基礎的瀏覽器，也可以從 Chrome 線上應用程式商店安裝。

## 手動安裝

適用於無法使用 Chrome 線上應用程式商店的情況。手動安裝的版本不會自動更新。

1. 在 [GitHub 版本列表]({{ site.github_url }}/tags) 中下載最新版本的 **Source code (zip)**，然後解壓縮。
2. 在 Chrome 網址列輸入 `chrome://extensions` 並按 Enter。
3. 打開右上角的 **開發人員模式**。
4. 點選 **載入未封裝項目**，選擇解壓縮後的資料夾（裡面有 `manifest.json` 檔案）。

### 更新手動安裝的版本

下載並解壓縮新版本，覆蓋原來的資料夾，然後在 `chrome://extensions` 中點選 LexiBridge 卡片上的重新載入按鈕。你的單字庫和設定會保留。

## 開始使用

- **選擇程度**：在 **英文程度** 頁面選擇國中、高中・學測、全民英檢中高級或 GRE。你已經會的單字不會被標出來。頁面上方可以切換釋義語言（繁體中文或简体中文）。
- **查看釋義**：打開任何英文網頁，生字下面會有一道金色筆畫。點選就能看到音標、詞性和釋義；連結裡的生字，把滑鼠停在上面即可。
- **移出認識的單字**：在單字卡片上點選 **認識了**，這個字就不會再被標出。點錯了可以復原。
- **加入新單字**：選取網頁上的一個英文單字，點選出現的 **加入單字庫** 按鈕。
- **在某個網站上關閉**：點選瀏覽器工具列裡的 LexiBridge 圖示，關閉目前網站的開關。

## 系統需求

Chrome 114 或更新版本，以及同等版本的 Edge 等 Chromium 瀏覽器。
