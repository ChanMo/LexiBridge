## 儲存在你瀏覽器裡的資料

LexiBridge 使用瀏覽器提供的擴充功能儲存空間保存以下內容，它們不會離開你的裝置：

- 你的單字庫：單字和釋義
- 你選擇的釋義語言和英文程度
- 停用的網站清單
- 標示樣式設定

你可以隨時在 **單字庫** 頁面匯出或清空單字庫。移除擴充功能時，這些資料會一併刪除。

## 權限說明

| 權限 | 用途 |
| --- | --- |
| 讀取網頁內容 | 在你打開的網頁上找出單字庫裡的單字並標出來。網頁內容只在你的瀏覽器裡處理，不會被傳送到任何地方。 |
| `storage` | 儲存上面列出的單字庫和設定。 |
| `tabs` | 在擴充功能的彈出視窗裡顯示目前的網站，用來開關該網站的標示，並統計本頁的生字數。 |
| `tts` | 朗讀單字。發音由瀏覽器的語音合成功能完成，使用的是瀏覽器和作業系統提供的語音。 |

## 網路連線

LexiBridge 不發出任何網路請求，釋義和分級都來自擴充功能內建的詞典。

LexiBridge 不包含廣告，也不包含任何統計或分析程式碼。

## 資料來源

擴充功能內建的英漢詞典、音標和考試分級來自開源專案 [ECDICT](https://github.com/skywind3000/ECDICT)，依 MIT 授權使用；繁體中文釋義以 [OpenCC](https://github.com/BYVoid/OpenCC) 轉換，繁體中文版和日文版的分級參考東京外國語大學投野研究室的 [CEFR-J Wordlist](https://www.cefr-j.org/download.html)；日文釋義來自公眾領域的英日詞典 [EJDict-hand](https://github.com/kujirahand/EJDict)。完整的第三方授權見擴充功能套件和 [GitHub 儲存庫]({{ site.github_url }}) 裡的 `THIRD_PARTY_NOTICES.md`。
