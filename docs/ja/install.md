## Chrome ウェブストアからインストール

1. [LexiBridge のストアページ]({{ site.store_url }})を開きます。
2. **Chrome に追加** をクリックし、確認画面で **拡張機能を追加** を選びます。
3. インストールが終わると **英語レベル** のページが開きます。自分に合ったレベルを選べば使い始められます。

ブラウザの言語が日本語なら、インストール後は自動的に日本語の意味と CEFR-J に基づくレベルを使います。Microsoft Edge など Chromium ベースのブラウザでも、Chrome ウェブストアからインストールできます。

## 手動でインストール

Chrome ウェブストアを使えない場合の方法です。手動でインストールした版は自動では更新されません。

1. [GitHub のバージョン一覧]({{ site.github_url }}/tags)から最新版の **Source code (zip)** をダウンロードし、展開します。
2. Chrome のアドレスバーに `chrome://extensions` と入力して Enter を押します。
3. 右上の **デベロッパー モード** をオンにします。
4. **パッケージ化されていない拡張機能を読み込む** をクリックし、展開したフォルダ（`manifest.json` が入っているフォルダ）を選びます。

### 手動でインストールした版を更新する

新しい版をダウンロードして展開し、元のフォルダに上書きしてから、`chrome://extensions` で LexiBridge の再読み込みボタンをクリックします。単語帳と設定はそのまま残ります。

## 使い始める

- **レベルを選ぶ**：**英語レベル** のページで、中学、高校・大学入試、英検準1級、GRE から選びます。もう知っている単語はマークされません。ページ上部で意味の言語（日本語、简体中文、繁體中文）を切り替えられます。
- **意味を見る**：英語の Web ページを開くと、知らない単語に金色の下線が引かれます。クリックすると発音記号と意味が表示されます。リンク内の単語は、マウスを重ねると表示されます。
- **覚えた単語を外す**：単語カードの **覚えた** をクリックすると、その単語はもうマークされません。間違えたときは元に戻せます。
- **新しい単語を追加**：Web ページ上の英単語を選択し、表示される **単語帳に追加** ボタンをクリックします。
- **特定のサイトでオフにする**：ツールバーの LexiBridge アイコンをクリックし、今のサイトのスイッチをオフにします。

## 動作環境

Chrome 114 以降、および同等のバージョンの Edge などの Chromium ベースのブラウザ。

うまく動かないときは、[GitHub]({{ site.github_url }}/issues) でお知らせください。
