## ブラウザに保存されるデータ

LexiBridge はブラウザの拡張機能用ストレージに次の内容を保存します。これらがお使いの端末の外に出ることはありません。

- 単語帳：単語とその意味
- 選んだ意味の言語と英語レベル
- 無効にしたサイトの一覧
- マークのスタイルの設定

単語帳は **単語帳** ページからいつでもエクスポートしたり、空にしたりできます。拡張機能を削除すると、これらのデータも一緒に削除されます。

## 権限について

| 権限 | 用途 |
| --- | --- |
| Web ページの内容の読み取り | 開いたページから単語帳にある単語を見つけてマークします。ページの内容はブラウザの中だけで処理され、どこにも送信されません。 |
| `storage` | 上に挙げた単語帳と設定を保存します。 |
| `tabs` | ポップアップに今のサイトを表示してマークのオン・オフを切り替え、このページの単語数を数えます。 |
| `tts` | 単語を読み上げます。発音はブラウザの音声合成機能で行い、ブラウザと OS が提供する音声を使います。 |

## ネットワーク通信

LexiBridge はネットワークリクエストを一切送信しません。意味とレベルは、拡張機能に内蔵された辞書から読み込みます。

LexiBridge に広告はなく、統計や分析のためのコードも含まれていません。

## データの出典

日本語の意味はパブリックドメインの英和辞書 [EJDict-hand](https://github.com/kujirahand/EJDict)、発音記号と試験別の単語分類はオープンソースプロジェクト [ECDICT](https://github.com/skywind3000/ECDICT)（MIT ライセンス）、レベルは東京外国語大学投野由紀夫研究室の [CEFR-J Wordlist](https://www.cefr-j.org/download.html) に基づいています。第三者のライセンスの全文は、拡張機能のパッケージと [GitHub リポジトリ]({{ site.github_url }})の `THIRD_PARTY_NOTICES.md` をご覧ください。
