原文で読みたい人のために

原文の手ざわりはそのままに、足りない数語だけを補います。

ページ全体を翻訳しない

原文は一語も変えません。マークされるのは知らない単語だけで、読める部分の邪魔はしません。

データは手元だけに

単語帳はブラウザの中に保存され、アカウントも不要です。LexiBridge にはサーバーがなく、何もアップロードしません。

変化形もわかる

studies、making、went も原形で認識するので、単語帳には 1 語だけあれば十分です。

LexiBridge をつくった理由

英語の原文を読むとき、よくある方法は二つです。英語が得意な人は知らない単語を読み飛ばし、そうでない人はページごと翻訳します。前者は読み終えても単語が身につかず、後者は内容がわかっても原文を読む力が育ちません。

LexiBridge はその間の道を選びます。原文はそのままに、足りない数語だけを補う。記事を一本読むたびにいくつか単語を覚え、覚えた単語はもう出てきません。

オープンソースのプロジェクトです。ご意見や開発への参加は GitHub でどうぞ。
