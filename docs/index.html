为读原文的人设计

保留原文的语感，只补上你缺的那几个词。

不翻译整页

原文一字不改。只有你不认识的词才会被标出，读得懂的部分不打扰你。

数据只在本地

词库存在你的浏览器里，不需要账号。LexiBridge 没有服务器，也不上传任何数据。

认得变形词

studies、making、went 都能找回原形，词库里只需要存一个词。

免费开源

MIT 协议，代码在 GitHub 上，可以自由使用、修改和分发。

为什么做 LexiBridge

读英文原文时，常见两种做法：英文好的人遇到生词就跳过去，英文没那么好的人干脆整页翻译。前一种读完了，词没学到；后一种看懂了，读原文的能力却没练到。

LexiBridge 想走中间那条路：保留原文，只把你缺的那几个词补上。每读一篇文章，就顺手认识几个词；认识了，它就不再出现。

这是一个开源项目，欢迎在 GitHub 上提建议或参与开发。
